# /guest-journey

Mapeie a jornada do convidado para: **$ARGUMENTS**

Use o subagente `guest-advocate` (tipo `imagineer:guest-advocate`). Entregue uma tabela por etapa:

`Etapa | O que o convidado faz | O que sente | Dor hoje | Oportunidade de encantamento`

Etapas mínimas: **Descoberta → Desejo → Decisão → Chegada/Compra → Uso → Problema → Lembrança/Indicação**.

No fim:
- **Os 3 piores momentos** (onde a experiência quebra hoje).
- **Os 3 momentos para virar mágicos** (onde um pequeno investimento muda tudo).
- **Uma frase que o convidado diria a um amigo** depois da versão ideal.
