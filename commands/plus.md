# /plus

Aplique **plussing** a: **$ARGUMENTS**

Se o argumento for um caminho de arquivo, leia-o primeiro.

Use o subagente `devils-plusser` (tipo `imagineer:devils-plusser`) e entregue:

1. **Versão atual** em 2 linhas (o que é, para quem).
2. **Rodada 1 — Encantamento:** o que transformaria isso em algo que o convidado conta para os amigos?
3. **Rodada 2 — Atrito zero:** onde o convidado espera, se confunde ou desconfia? Como sumir com isso?
4. **Rodada 3 — Ousadia:** o que ninguém do setor faria? Faça uma versão assim.
5. **Versão "plussed"** em 1 parágrafo + o detalhe que ninguém pediu mas todos vão lembrar.
6. **Custo do plus:** baixo / médio / alto para cada melhoria.
